# 宿舍电量监控

这是一个 AstrBot 插件，用于查询北航宿舍的空调、照明电表余额，并在每天指定时间执行检查。

## 功能

- 在 AstrBot 仪表盘选择校区、楼宇、楼层和房间，查询并填入电表号。
- 空调电表号和照明电表号也可以直接手动输入。
- 分别设置空调、照明的余额预警阈值。
- 设置每日检查时间（24 小时制 `HH:MM`）和接收通知的纯数字 QQ 号。
- 每次定时检查发现余额低于阈值都会发送提醒，不做“只提醒一次”去重。
- 功率字段无法从上游页面读取时显示“未知”，不会按 0 计算。
- 可使用 `/查询宿舍电量`（别名 `/宿舍电量`）查询当前配置下的空调和照明余额。

## 安装与配置

将插件目录放入 `AstrBot/data/plugins/astrbot_plugin_buaa_power`，在 AstrBot 中重载插件，然后打开插件详情页的“宿舍电量监控”页面。

插件初始配置中的校区、楼宇、楼层、房间、电表号和通知 QQ 号均为空，不包含任何个人位置。首次使用时：

1. 选择完整位置并点击“查询电表”，按电表地址将对应编号填入；也可以直接输入两个电表号。
2. 输入空调和照明阈值、通知 QQ 号和每日检查时间。
3. 勾选“启用监控”并保存设置。

手动“立即检查”不会修改配置。未配置完整时不会访问上游站点，也不会发送消息。

## 指令

发送 `/查询宿舍电量` 或 `/宿舍电量` 后，插件会查询当前配置的两个电表并在当前会话回复余额。该指令不会触发低余额 QQ 通知；未配置完整或单个电表查询失败时，会在回复中说明原因。

## 数据来源

插件访问北航宿舍电量查询站点：<http://shsd.buaa.edu.cn/PubBuaa>。只使用公开的电表列表和详情页面，不保存站点 Cookie、密码或其他登录凭据。

## 依赖

AstrBot 已提供的 `httpx` 和 `apscheduler` 可直接复用；独立安装插件时也可以执行：

```bash
pip install -r requirements.txt
```
